# Zero Hour Map Library

Community maps for **Command & Conquer: Generals – Zero Hour**, packed one map per file for
Command Center's map library.

| Folder / file | What it holds |
| --- | --- |
| `catalog.json` | Every map: name, players, size, SHA-256, start positions, whether it uses `map.ini` rules or scripts |
| `maps/<id>.zip` | One map, inside a folder named like the map, ready for `Documents\Command and Conquer Generals Zero Hour Data\Maps` |
| `previews/<id>.png` | The map's own preview picture |
| `EXCLUDED.md` | Maps that were left out and why |

## How it is built

The library is generated by `tools/MapLibraryBuilder` in the Command Center repository:

- only map files are packed (`.map .tga .ini .str .txt .scb .wak`); programs, documents and stray files never are;
- identical maps are packed once;
- maps that ship with the game are left out;
- maps without start positions (missions, broken files) are left out;
- maps whose readme asks not to share or host them are left out.

## Map authors

Every map belongs to its author. Readme and credit files that came with a map stay inside its zip.
If you made one of these maps and want it changed or removed, open an issue and it will be taken down.
